# Mugshot 隐私政策（模板）

> 本文件为 Mugshot 项目隐私政策模板。Android App 内置同内容政策（首启展示）。
> 部署者请按自身情况补充"数据控制者"等条目后对外发布。

最后更新：2026-11-10

## 1. 收集的内容

在你明确同意后，Mugshot App 仅采集并向你自行部署的 mugshot-server 上报以下设备状态：

- 屏幕亮/灭状态
- 当前前台应用名称与包名（仅"哪个应用正在使用"，不涉及应用内容）
- 电池电量、充电状态与充电方式（交流电 / USB / 无线）
- 网络类型（Wi-Fi / 移动数据 / 无网络）
- 设备型号与你自定义的设备名称

## 2. 不收集的内容

- 通讯录、短信、通话记录、照片、位置信息
- 任何应用内的浏览记录、输入内容、剪贴板
- 除上述字段外的任何其他个人信息

## 3. 数据的传输与存储

- 数据仅发送到你自行配置的 mugshot-server 地址（传输协议为 WebSocket / HTTPS 明文由部署者选择）
- 服务器以 JSON 文件形式保存设备最近状态与历史记录，默认保留 7 天（`retention_days` 可调），到期自动清理
- 项目开发者不收集、不中转、不存储任何用户数据

## 4. 权限用途

| 权限 | 用途 | 是否必需 |
|------|------|----------|
| 使用情况访问权限（PACKAGE_USAGE_STATS） | 获取前台应用名称 | 可选（拒绝后该字段为空） |
| 通知权限（POST_NOTIFICATIONS） | 展示常驻上报通知 | Android 13+ 必需 |
| 电池优化白名单 | 保持后台稳定上报 | 可选 |
| 安装未知应用 | 应用内更新下载安装 | 可选（仅手动触发更新时） |

## 5. 数据控制

- 你可以随时在 App 设置中停止服务，或直接卸载应用
- 服务端数据的保留期限与删除由部署 mugshot-server 的管理员（通常是你本人）控制
- 设备 ID 为应用首次启动时随机生成的 UUID，仅用于服务端区分设备，与任何账号身份无关

## 6. 未成年人

Mugshot 面向普通用户，不针对未成年人收集任何信息。

## 7. 政策变更

如有重大变更，将在应用更新时在隐私政策页公示。
