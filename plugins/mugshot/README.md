# Mugshot 插件（TRSS-Yunzai）

基于 TRSS-Yunzai 的设备状态远程查看插件。群成员在 QQ 群内发送指令，即可查看群主 Android 设备的当前使用状态：正在使用什么 App、屏幕是否亮着、电量、充电状态、网络类型、设备名称等。支持多台设备，每台设备在 App 内自定义名称，群内按设备名查询。

本仓库 `main` 分支根目录即插件本体（用于直接克隆安装）。服务端与安卓端的完整项目见 `master` 分支。

## 安装

把本插件克隆到 TRSS-Yunzai 的 `plugins/` 目录：

```bash
# 进入 Yunzai 根目录的 plugins
cd Yunzai-Bot/plugins

# 克隆插件（main 分支即插件本体）
git clone -b main https://github.com/huliaiya/Mugshot.git mugshot
```

依赖说明：

- 需要先部署并运行 `mugshot-server`，获取其访问地址与统一 Token
- WebSocket 订阅使用 Yunzai 根目录自带的 `ws` 依赖；Node 22+ 也可使用内置 WebSocket。缺失时插件自动降级为纯 HTTP 查询
- 插件无独立构建步骤，克隆后重启 Yunzai 即可加载

## 配置

配置文件为 `config/mugshot.yaml`，插件启动时会自动生成。可手工编辑，也可在锅巴面板（Guoba）里可视化修改，两种方式共用同一份配置，改完即时生效，无需重启 Yunzai。

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `server_url` | `http://127.0.0.1:8080` | mugshot-server 地址（含端口） |
| `token` | 空 | 统一 Token，与手机 App 共用同一个；在服务端 GUI 的"设置"或"接入信息"页获取 |
| `plugin_token` | 空 | 兼容旧配置的令牌键名，`token` 为空时作为后备 |
| `detail_fresh` | `true` | `#群主详情` 是否默认触发一次实时上报 |
| `fresh_timeout_ms` | `8000` | 等待设备按需上报的超时（毫秒） |
| `fresh_cooldown_ms` | `10000` | 同一用户重复触发实时上报的最小间隔（毫秒），冷却期内自动展示缓存数据 |
| `device_btn_per_row` | `5` | 设备选择卡片每行放几个按钮（最多 10） |
| `github_repo` | `huliaiya/Mugshot` | 插件与服务端更新检查使用的 GitHub 仓库（格式 `owner/repo`） |
| `auto_update_check` | `true` | 启动时与每日 9 点检查更新（仅写日志提示，不自动更新） |

### 锅巴面板（Guoba）

若已安装锅巴面板（guoba-plugin-next），插件会在面板中注册"服务端连接""查询行为""更新"三组可视化字段，并提供"测试连接"按钮：用表单里填写的地址与 Token 请求一次服务端 `/health`，验证连通性。在面板里修改服务端地址或 Token 并保存后，插件会自动断开旧订阅并按新配置重连。

## 指令

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `#群主帮助` | 查看指令列表 | 所有人 |
| `#群主列表` | 渲染所有设备列表（在线状态、最后上报时间），附选择按钮 | 所有人 |
| `#群主查看 [设备名]` | 查询设备当前状态，默认触发一次实时上报（fresh），返回 live 数据；设备离线或超时降级返回 cache 数据 | 所有人 |
| `#群主在干嘛 [设备名]` | 同 `#群主查看` | 所有人 |
| `#群主详情 [设备名]` | 返回完整字段状态卡片 | 所有人 |
| `#群主状态` | 查看服务端健康状态与版本、可用更新 | 所有人 |
| `#群主更新` | 一条指令检查并直接更新服务端与插件（并行检查，哪端有更新就更新哪端，单端失败不影响另一端） | Master |

说明：

- 不带设备名且存在多台设备时，插件渲染设备选择图片并附按钮，不随意挑选某一台
- 所有回复均优先渲染为图片；QQBot 适配器下附带可点击按钮，其他协议端自动降级为纯图片
- 实时上报有冷却（`fresh_cooldown_ms`），同一用户短时间内重复触发会自动展示缓存数据，避免频繁唤醒手机

## 更新

- 启动时与每日定时检查更新，仅记录日志；`#群主更新` 可直接更新服务端与插件
- 插件更新直接跟随本仓库 `main` 分支；服务端更新走服务端自更新链路（下载新版本替换二进制后自动重启）
- 更新检查使用 `github_repo` 配置的仓库，主源失败时自动尝试镜像

## 安全与隐私

- 插件仅转发状态字段（前台应用名称、屏幕、电量、网络类型等），不上传输入内容、屏幕文本、剪贴板等敏感数据
- 插件、手机 App 与服务端 GUI 共用同一个 Token 鉴权
- 服务端轮换 Token 后旧 Token 立即失效；插件收到 401 时会自动从本机服务端同步新 Token 并重试一次（远程服务端需手动填写）
